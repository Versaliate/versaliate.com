How it works

The console is your central editor. Versux supports variables, conditions, lists, functions and events. The -:- operator connects values to functions. Reachable devices can report their state and execute supported commands.

Requirements

Start with an Ektiven-powered console and basic software. Device access requires a suitable data route and the appropriate control rights. Saving a program and starting it are separate actions.

In the current prototype

Program media are written at a programming station and started explicitly. Memory holds values on the executing device; external Versux data storage extends data capacity. A compute station can run several assigned programs. Storage capacity and computing power remain separate limits.

  • Console: editing and management
  • Program media: named software with a revision
  • Compute station: several assigned programs

A first program

Run once on a powered console with basic software while its console program is stopped. This example stores text in local Memory and prints it.

Memory.Notiz -:- Change "Hallo Versalox"
