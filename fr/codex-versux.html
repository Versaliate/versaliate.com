En développement

Découvrir le développement →

Fonctionnement

La console est votre éditeur central. Versux prend en charge variables, conditions, listes, fonctions et événements. L’opérateur -:- relie les valeurs aux fonctions. Les appareils accessibles peuvent signaler leur état et exécuter les commandes prises en charge.

Prérequis

Commencez avec une console alimentée en Ektiven et le logiciel de base. L’accès aux appareils nécessite une liaison de données adaptée et les droits de contrôle correspondants. Enregistrer et démarrer un programme sont deux actions distinctes.

Dans le prototype actuel

Les supports de programme sont écrits à une station de programmation et démarrés explicitement. Memory conserve les valeurs sur l’appareil exécutant le code ; les stockages de données Versux externes étendent la capacité. Une station de calcul peut exécuter plusieurs programmes attribués. Capacité mémoire et puissance de calcul restent des limites séparées.

  • Console : édition et gestion
  • Support : logiciel nommé avec révision
  • Station de calcul : plusieurs programmes attribués

Un premier programme

Exécutez une fois sur une console alimentée, avec le logiciel de base, lorsque son programme est arrêté. Cet exemple enregistre un texte dans le Memory local et l’affiche.

Memory.Notiz -:- Change "Hallo Versalox"
Memory.Notiz -:- Read -:- Print
