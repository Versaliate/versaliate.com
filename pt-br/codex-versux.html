Como funciona

O console é seu editor central. Versux oferece variáveis, condições, listas, funções e eventos. O operador -:- conecta valores a funções. Dispositivos acessíveis podem informar seu estado e executar comandos compatíveis.

Requisitos

Comece com um console alimentado por Ektiven e software básico. O acesso a dispositivos exige uma rota de dados adequada e os direitos de controle correspondentes. Salvar um programa e iniciá-lo são ações separadas.

No protótipo atual

Mídias de programas são gravadas em uma estação de programação e iniciadas explicitamente. Memory mantém valores no dispositivo que executa o código; o armazenamento externo de dados Versux amplia a capacidade. Uma estação de cálculo pode executar vários programas atribuídos. Capacidade de armazenamento e poder de cálculo são limites separados.

  • Console: edição e gestão
  • Mídia: software com nome e revisão
  • Estação de cálculo: vários programas atribuídos

Um primeiro programa

Execute uma vez em um console alimentado e com software básico, com seu programa parado. O exemplo salva um texto no Memory local e o exibe.

Memory.Notiz -:- Change "Hallo Versalox"
Memory.Notiz -:- Read -:- Print
