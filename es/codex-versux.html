Versux · Programas y automatización

El lenguaje del juego conecta dispositivos, eventos, valores guardados y tus propios programas.

Cómo funciona

La consola es tu editor central. Versux admite variables, condiciones, listas, funciones y eventos. El operador -:- conecta valores con funciones. Los dispositivos accesibles pueden comunicar su estado y ejecutar órdenes compatibles.

Requisitos

Empieza con una consola alimentada con Ektiven y software básico. Acceder a dispositivos requiere una ruta de datos adecuada y los derechos de control correspondientes. Guardar un programa e iniciarlo son acciones distintas.

En el prototipo actual

Los soportes de programas se escriben en una estación de programación y se inician expresamente. Memory guarda valores en el dispositivo que ejecuta el código; el almacenamiento de datos Versux externo amplía la capacidad. Una estación de cálculo puede ejecutar varios programas asignados. Capacidad de almacenamiento y potencia de cálculo son límites separados.

  • Consola: edición y gestión
  • Soporte: software con nombre y revisión
  • Estación de cálculo: varios programas asignados

Un primer programa

Ejecuta una vez en una consola alimentada y con software básico, con su programa detenido. El ejemplo guarda un texto en Memory local y lo muestra.

Memory.Notiz -:- Change "Hallo Versalox"
Memory.Notiz -:- Read -:- Print
